# 0001 — Independent plugin services

Accepted October 1, 2026 through the implementation brief confirmation.

The port uses an npm workspace producing separate s2script `.s2sp` archives for core, storage, karma, bodies, shop, communication, reports, UI, features, and item effects. Shared source libraries are pure; authoritative state belongs to the published provider. Protocol-2 declarations live with their producer and use synchronous finite copied records. Async storage operations return IDs with status/completion notifications.

Reloadable dependencies use generation-scoped optional attachments with explicit readiness policy. Optional attachment describes reconnection behavior, not permission to omit enabled gameplay. Provider disappearance withdraws catalog entries and cleans owned effects. Core reload terminates the active round and invalidates round work, while durable records survive.

This avoids the old monolith's shared arrays and effect bus becoming disconnected copies across bundles. It requires contract/build checks, stable identity and explicit transaction compensation rather than relying on import order or notification delivery as authorization.
