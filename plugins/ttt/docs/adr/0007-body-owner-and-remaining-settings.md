# ADR0007 — Preserve canonical corpse ordering and finish current owner configuration

Accepted October2,2026, against the existing-port implementation.

Bodies alone owns the canonical corpse array/indexes, interactions, prop carry state and beams. Native creation and canonical insertion finish before Core marks logical death, spoofs the victim or emits bodyCreate. Cancellation sends Kill while retaining indexed metadata until the original clear/replacement paths. Queries retain stale tracked metadata. No delayed draft/commit step or new exclusive carry policy is introduced.

Core retains only an invocation-local event projection pinned to its Bodies attachment and full entity identity. DNA and Paint assignments write immediately to that canonical record; subsequent observer copies read current mutable metadata. Mutation-after-throw survives the ordered bridge. The private target and accessors never cross Protocol2: external payloads and published dispatch results are plain copies. Retiring reads are checked again after the external owner call, and replacement cannot redirect an old mutation or corpse settle/pawn-hide job.

The original Core PRE queue drives corpse settle and Bodies tickets. Disconnect release tickets use a null actor, preserving their original map/round/prop guard. Native creation and Beam.draw returns are retired when unload happens inside the call; a completed unload cannot be followed by repopulating closed state or retaining an unowned returned beam. Cleanup uses captured resources without requiring Core to remain available.

Core owns its remaining25 legacy settings and existing canonical-only phrases_file. World owns its actual three settings. The pure configuration adapter includes declared canonical-only fields in materialization/persistence while registering aliases only, and refuses duplicate paths. Four aggregate refresh sites and three separate catalog refresh sites remain. Translations stay startup-only, dormant settings stay dormant, and effective old defaults are retained. The importer covers169 aliases across five canonical files. Body's five controls remain Core-owned in this bounded extraction; their eventual configuration move must preserve the settle/hide timing.
