## Tripwire defects and policies to avoid inheriting

These are source-derived findings/inferences; they were not reproduced live during this audit.

1. **Pending arming crosses teardown.** Delay callback is not canceled, not scoped to round/map identity, and does not recheck state, owner, or prop validity ([TripwireItem.cs:92-105](https://github.com/edgegamers/TTT/blob/80716fba705a42ea60bfae0095b5a222e9eba7d1/TTT/CS2/Items/Tripwire/TripwireItem.cs#L92-L105)). Unarmed prop is not yet in ActiveTripwires; FINISHED only cleans ActiveTripwires (`79-89,173-174`). A round that ends inside initiation delay can leave a prop and spawn a new wire into the next round. Failed beam creation can also orphan the prop (`170-174`). Prefer one registered lifecycle object from placement onward with explicit Placing/Arming/Armed/Defusing/Resolved states and round/map scope.
2. **Clock mismatch for karma grace.** Instance timestamp uses `DateTime.UtcNow` ([TripwireItem.cs:173](https://github.com/edgegamers/TTT/blob/80716fba705a42ea60bfae0095b5a222e9eba7d1/TTT/CS2/Items/Tripwire/TripwireItem.cs#L173)), age uses `DateTime.Now` ([TripwireMovementListener.cs:148](https://github.com/edgegamers/TTT/blob/80716fba705a42ea60bfae0095b5a222e9eba7d1/TTT/CS2/Items/Tripwire/TripwireMovementListener.cs#L148)). In non-UTC host zones, the apparent age differs by local UTC offset. Also timestamp starts at arming, not placement. Use monotonic game time and choose placement vs armed-time grace semantics.
3. **Cross trace has no explicit endpoint cap.** TraceShape takes start + direction angle, not end; EndPos supplies only angle ([TripwireMovementListener.cs:65-73](https://github.com/edgegamers/TTT/blob/80716fba705a42ea60bfae0095b5a222e9eba7d1/TTT/CS2/Items/Tripwire/TripwireMovementListener.cs#L65-L73)). There is no distance/end check after result. Dependency implementation may cap/stop on the opposite wall, but source does not establish it; a missing/moved endpoint or pass-through surface could trigger behind the beam. Use an explicit bounded segment and exclude own anchor(s).
4. **Damage pipeline ignores cancellation/rescaling.** `dealTripwireDamage` dispatches an event then always subtracts original damage (`140-160`), never checking cancel or rewritten damage. Lethal branch has a death event without a preceding damage event. A central authoritative damage service should own damage -> modifier/cancellation -> health -> single death -> corpse/karma/log/win consequences.
5. **Sound after removal.** ActivateTripwire removes prop before calling its EmitSound ([TripwireMovementListener.cs:51-57](https://github.com/edgegamers/TTT/blob/80716fba705a42ea60bfae0095b5a222e9eba7d1/TTT/CS2/Items/Tripwire/TripwireMovementListener.cs#L51-L57)). Validity behavior depends on deferred removal; emit positional cue before deletion.
6. **Defuse races/stale object.** Scheduled ticks do not have cancellation handles or per-wire exclusive defuser. `progress >= 1` runs before revalidating target/membership ([TripwireDefuserListener.cs:103-118](https://github.com/edgegamers/TTT/blob/80716fba705a42ea60bfae0095b5a222e9eba7d1/TTT/CS2/Items/Tripwire/TripwireDefuserListener.cs#L103-L118)). Multiple defusers can each schedule completion; wire may already have exploded/been removed. Check object state, player liveness/identity, round, held USE and current target before any completion/reward. Tick delay hardcodes 64 (`126-128`) instead of engine rate.
7. **Placement/credit transaction incomplete.** Too-far gets refund ([TripwireItem.cs:127-131](https://github.com/edgegamers/TTT/blob/80716fba705a42ea60bfae0095b5a222e9eba7d1/TTT/CS2/Items/Tripwire/TripwireItem.cs#L127-L131)), but failed trace/pawn/entity/beam does not. CSS shop debits and gives item before OnPurchase completion, `TTT/Shop/Shop.cs:74-88,122-125`; no delivery result. Fresh shop should reserve/commit/refund explicitly or sell held placement charges.
8. **Blast occlusion is absent.** Distance-only damage loop damages through walls (`TripwireMovementListener.cs:55-57,99-108`). Decide whether to preserve this or trace explosion line-of-sight.
