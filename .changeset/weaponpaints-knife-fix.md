Knives now always show the chosen model. A stock knife is swapped for a newly given knife of the chosen class instead of being changed in place, which left the knife invisible or drawn backwards once the player already held it. `!st` is no longer a default StatTrak alias, so it no longer clashes with the JailBreak warden's `!st`.
