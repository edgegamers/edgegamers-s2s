# Triage labels

| Role and label | Meaning |
| --- | --- |
| `needs-triage` | Maintainer needs to evaluate the issue |
| `needs-info` | Waiting for information from the reporter |
| `ready-for-agent` | Fully specified and ready for agent implementation |
| `ready-for-human` | Requires human implementation |
| `wontfix` | Will not be actioned |

Use these labels when a skill names the corresponding triage role. Other existing repository labels may coexist.
