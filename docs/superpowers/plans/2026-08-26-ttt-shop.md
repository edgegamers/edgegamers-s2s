# TTT Shop Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `@edgegamers/ttt-shop` as the credits, purchase, menu, and stock item module for modular TTT.

**Architecture:** Shop consumes `TttCoreApi`, optionally consumes `TttKarmaApi`, publishes `TttShopApi`, and registers stock items through its own public API. Large legacy item/effect files are split by item family before they become module internals.

**Tech Stack:** TypeScript 5.9, Source2Script plugin API, `@s2script/cs2`, `@edgegamers/ttt-core`, optional `@edgegamers/ttt-karma`, Node test runner.

**Spec:** `docs/superpowers/specs/2026-08-26-ttt-modular-design.md`

## Global Constraints

- Create `plugins/cs2/ttt/shop/`.
- Package name is `@edgegamers/ttt-shop`.
- Required plugin dependency: `@edgegamers/ttt-core`.
- Optional plugin dependency: `@edgegamers/ttt-karma`.
- Every stock item has `enabled`, `price`, role/team eligibility, and relevant effect settings.
- Stock items register through the same public API as third-party items.
- Keep first-party plugin manifests `private: true` until a later public promotion.
- Run `npm.cmd run lint`, `npm.cmd run typecheck`, `npm.cmd test`, and `npm.cmd run build` before completion.

---

## File Structure

- `plugins/cs2/ttt/shop/package.json`: shop manifest, core dependency, optional karma dependency, config.
- `plugins/cs2/ttt/shop/api.d.ts`: public shop API.
- `plugins/cs2/ttt/shop/src/plugin.ts`: plugin entry and API publish.
- `plugins/cs2/ttt/shop/src/shop.ts`: balances, item registry, purchase flow.
- `plugins/cs2/ttt/shop/src/config.ts`: shop and item config snapshot.
- `plugins/cs2/ttt/shop/src/commands.ts`: shop, buy, balance, give commands.
- `plugins/cs2/ttt/shop/src/economy.ts`: kill, assist, body, and exploration credits.
- `plugins/cs2/ttt/shop/src/items/*.ts`: stock item families.
- `plugins/cs2/ttt/shop/test/shop.test.ts`: registry, gating, refunds.
- `plugins/cs2/ttt/shop/test/economy.test.ts`: optional karma scaling behavior.

- [ ] **Step 3: Add public API**

Create `api.d.ts`:

```ts
export type TttPurchaseResult =
  | "success"
  | "insufficient_funds"
  | "not_found"
  | "not_purchasable"
  | "wrong_role"
  | "canceled"
  | "limit_reached"
  | "delivery_failed";

export interface TttShopItem {
  id: string;
  name: string;
  description: string;
  price: number;
  enabled: boolean;
  allowedRoles?: readonly string[];
  allowedTeams?: readonly string[];
  limit?: number;
  canPurchase?(slot: number): TttPurchaseResult | "success";
  onPurchase(slot: number): void | boolean;
}

export interface TttShopApi {
  registerItem(item: TttShopItem): void;
  itemById(id: string): TttShopItem | null;
  allItems(): readonly TttShopItem[];
  balanceOf(slot: number): number;
  addBalance(slot: number, amount: number, reason?: string, notify?: boolean): void;
  setBalance(slot: number, amount: number, reason?: string, notify?: boolean): void;
  tryPurchase(slot: number, itemId: string, notify?: boolean): TttPurchaseResult;
  canPurchase(slot: number, itemId: string): TttPurchaseResult;
}
```

import assert from "node:assert/strict";
import { describe, it } from "node:test";
import { createShopApi } from "../src/shop.ts";

function fakeCore(role = "ttt:traitor") {
  return {
    roleOf: () => role,
    teamOfRole: (key: string) => key === "ttt:traitor" ? "traitor" : "innocent",
    gameState: () => ({ state: "in_progress", participants: 2, roundsThisMap: 1, winner: "" }),
    log: () => undefined,
  };
}

describe("TTT shop", () => {
  it("refuses disabled items", () => {
    const shop = createShopApi(fakeCore());
    shop.registerItem({ id: "armor", name: "Armor", description: "", price: 1, enabled: false, onPurchase: () => undefined });
    shop.setBalance(1, 10, "", false);
    assert.equal(shop.tryPurchase(1, "armor", false), "not_purchasable");
  });

  it("refunds delivery failures", () => {
    const shop = createShopApi(fakeCore());
    shop.registerItem({ id: "tripwire", name: "Tripwire", description: "", price: 5, enabled: true, onPurchase: () => false });
    shop.setBalance(1, 10, "", false);
    assert.equal(shop.tryPurchase(1, "tripwire", false), "delivery_failed");
    assert.equal(shop.balanceOf(1), 10);
  });

  it("enforces role gates", () => {
    const shop = createShopApi(fakeCore("ttt:innocent"));
    shop.registerItem({ id: "c4", name: "C4", description: "", price: 1, enabled: true, allowedTeams: ["traitor"], onPurchase: () => undefined });
    shop.setBalance(1, 10, "", false);
    assert.equal(shop.tryPurchase(1, "c4", false), "wrong_role");
  });
});

- [ ] **Step 3: Implement `createShopApi`**

Create a slot-indexed balance table, item map, purchase-count table, and exact purchase result strings from `api.d.ts`.

Core logic:

```ts
if (!item.enabled) return "not_purchasable";
if (core.gameState().state !== "in_progress") return "not_purchasable";
if (item.allowedRoles?.includes(core.roleOf(slot)) === false) return "wrong_role";
if (item.allowedTeams?.includes(core.teamOfRole(core.roleOf(slot))) === false) return "wrong_role";
if (item.price > balances[slot]!) return "insufficient_funds";
```

Debit before delivery, then refund when `onPurchase(slot) === false`.

export interface KarmaReader {
  karmaOf(slot: number): number;
}

export function scaleExplorationReward(base: number, karma: KarmaReader | null, slot = 0): number {
  if (karma === null) return base;
  return Math.trunc(base * Math.max(0, karma.karmaOf(slot)) / 100);
}
