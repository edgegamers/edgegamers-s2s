# Edgegamers s2script plugins

Server plugins maintained by edgegamers and distributed through the s2script registry.

## Language

**Plugin**: A server extension with its own identity and runtime lifecycle.

**Bundle**: A named registry package that groups plugins for installation together.

**Bundle member**: A plugin included in a bundle while retaining its own runtime identity.

**Shared library**: Reusable source incorporated into consuming plugins rather than loaded as its own runtime plugin.

**Release unit**: A plugin or bundle versioned independently of unrelated plugins and bundles.

**Registry distribution**: Access to a published package through the registry, either public or restricted to its organization's members.

**Source visibility**: Who may read a plugin's source repository; separate from registry distribution.
